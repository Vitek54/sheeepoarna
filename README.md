## Rate Limits

Скрипт полностью обрабатывает все rate limits Discord API v10:

- Отслеживание `X-RateLimit-Remaining` / `X-RateLimit-Reset-After` заголовков
- Автоматическое ожидание при 429 (per-route и global, scope-aware)
- Bucket-based rate limiting (по маршруту + ресурсу)
- Экспоненциальный backoff при сетевых ошибках и 5xx
- До 10 повторных попыток на каждый запрос
- Задержка 0.35с между удалениями для превентивного соблюдения лимитов

## Установка

```bash
pip install -r requirements.txt
```

Зависимости:
- `httpx` — асинхронный HTTP клиент
- `rich` — красивый вывод в терминал

## Запуск

```bash
python discord_tool.py
```

При запуске вводишь свой Discord токен → открывается чёрно-белое минималистичное меню.
