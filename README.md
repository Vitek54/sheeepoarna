# Discord Self-Tool

Минималистичная чёрно-белая CLI-утилита для управления Discord аккаунтом.

## Возможности

- **Удаление сообщений** — везде / в конкретном канале / на всех серверах / на конкретном сервере
- **Парсинг участников по роли** — мгновенное получение ID через role-members API
- **Поиск сообщений** — поиск по ключевому слову на сервере
- **Экспорт канала** — сохранение всех сообщений канала в JSON
- **Информация о сервере** — участники, бусты, роли, эмодзи
- **Кастомный статус** — установка текста и эмодзи статуса

## Rate Limits

Скрипт полностью обрабатывает все rate limits Discord API:

- Отслеживание `X-RateLimit-Remaining` / `X-RateLimit-Reset-After` заголовков
- Автоматическое ожидание при 429 (per-route и global)
- Bucket-based rate limiting (по маршруту + ресурсу)
- Экспоненциальный backoff при сетевых ошибках и 5xx
- До 10 повторных попыток на каждый запрос

## Установка

```bash
pip install -r requirements.txt
```

Зависимости:
- `httpx` — асинхронный HTTP клиент
- `rich` — красивый вывод в терминал

## Запуск

```bash
python discord_tool.py
```

При запуске вводишь свой Discord токен → открывается меню.

## Как получить токен

1. Открой Discord в браузере
2. `F12` → Console
3. Вставь:
   ```js
   (webpackChunkdiscord_app.push([[''],{},e=>{m=[];for(let c in e.c)m.push(e.c[c])}]),m).find(m=>m?.exports?.default?.getToken!==void 0).exports.default.getToken()
   ```
4. Скопируй результат (без кавычек)
